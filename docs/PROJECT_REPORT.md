# RH56DFTP-2L 左手灵巧手视觉跟随项目报告

## 1. 项目概述

本项目实现了一套基于普通电脑摄像头的灵巧手手指跟随系统。系统识别操作者的左手手部关键点，将手指弯曲程度转换为六轴控制目标，并通过 USB-RS485 向因时 RH56DFTP-2L 左手灵巧手发送角度命令。

项目面向单手指跟随演示和基础人机交互验证，不包含力控、抓取规划、三维姿态估计或自主视觉识别任务。

## 2. 项目内容

### 2.1 硬件与通信

- 灵巧手型号：因时 RH56DFTP-2L 左手。
- 供电：灵巧手独立 24V 供电。
- 通信：USB-RS485 转接器。
- 已标定串口：`COM3`。
- 波特率：`115200`。
- 手部 ID：`1`。

灵巧手上位机与本项目不能同时打开，因为两者都会占用同一个串口。

### 2.2 软件结构

```text
摄像头画面
    -> MediaPipe HandLandmarker
    -> 21 个手部关键点
    -> 六轴映射与方向标定
    -> 安全过滤（限幅、死区、频率）
    -> RH56 串口协议帧
    -> RH56DFTP-2L 灵巧手
```

核心模块如下：

- `app.py`：摄像头循环、MediaPipe 调用、窗口显示和键盘控制。
- `mapper.py`：从手部关节夹角计算四指和大拇指控制目标。
- `safety.py`：控制输出保护，防止高频或微小抖动命令直接发送到硬件。
- `rh56.py`：六轴角度数据的串口帧封装与发送。
- `config.py`：配置读取和参数校验。

### 2.3 最终手指映射

| 轴序号 | 控制对象 | 最终策略 |
| --- | --- | --- |
| 1 | 小拇指 | 两个关节夹角平均值，反向输出。 |
| 2 | 无名指 | 两个关节夹角平均值，反向输出。 |
| 3 | 中指 | 两个关节夹角平均值，反向输出。 |
| 4 | 食指 | 两个关节夹角平均值，反向输出。 |
| 5 | 大拇指弯曲 | 使用大拇指 MCP-IP-指尖的夹角控制。 |
| 6 | 大拇指旋转 | 固定在已标定值 `1000`，不跟随画面横向移动。 |

当前实机参数为：`motion_scale: 1.0`、`send_hz: 10`、`deadband: 4`，并将前四个手指轴设置为反向。

## 3. 构建过程

### 3.1 建立运行环境

1. 创建项目目录及 Python 虚拟环境 `.venv`。
2. 安装 `MediaPipe`、`OpenCV`、`PySerial`、`PyYAML` 与 `pytest`。
3. 放置 MediaPipe 手部识别模型 `assets/hand_landmarker.task`。
4. 建立 YAML 配置文件和 Python 包结构。

### 3.2 先完成不接硬件的视觉预览

使用 `--no-serial` 模式验证摄像头能够打开、画面能够镜像、手部关键点以黄色点位显示。该步骤不占用 `COM3`，不会驱动灵巧手。

### 3.3 接入串口与安全保护

1. 根据 RH56 通信格式实现六个 16 位角度值的写入帧。
2. 设置 RH56 角度寄存器地址为 `1486`。
3. 加入发送频率限制、死区和行程限幅。
4. 取消串口启动时自动发送张开姿态，避免程序刚启动就产生未经确认的运动。

### 3.4 进行手势与轴向标定

通过因时上位机确认实际电机都能正常驱动，再逐项校准视觉映射：

1. 摄像头镜像后，MediaPipe 将物理左手标记为 `Right`；程序据此接受 `Right` 标签。
2. 前四指最初动作方向相反，因此在配置中将前四轴设置为反向。
3. 提高四指弯曲增益至 `13`，使紧握时可达到完整控制行程。
4. 大拇指横向位置直接映射到第六轴时会出现错误外摆，因此固定第六轴。
5. 大拇指仅使用指尖上下位置时，握拳无法可靠收拢；最终改为使用大拇指关节夹角控制第五轴。

### 3.5 提供独立启动方式

新增 `启动灵巧手跟随.bat`。日常使用时双击此文件即可启动，无需通过对话或手工输入命令。

## 4. 遇到的困难与解决方法

| 困难 | 原因 | 解决方法 |
| --- | --- | --- |
| 上位机与程序无法同时控制 | 两个程序同时占用 `COM3`。 | 运行本项目之前关闭因时上位机；按 `Esc` 退出本项目后串口释放。 |
| 摄像头可见但左右手标签相反 | 自拍画面进行了镜像。 | 程序接受 MediaPipe 的 `Right` 标签作为操作者的物理左手。 |
| 四指伸弯方向相反 | 视觉角度的数值方向与设备轴方向不同。 | 在 `config.yaml` 中反向前四个轴。 |
| 四指握拳幅度不足 | 原始关节夹角增益不足。 | 将四指弯曲增益从 `10` 调整为 `13`，并保留 `0-1000` 限幅。 |
| 大拇指被带到横向错误姿态 | 第六轴随画面中的横向位移变化，但该轴在正确姿态中应保持稳定。 | 固定第六轴为标定值 `1000`。 |
| 大拇指握拳时不向掌心收拢 | 仅使用指尖上下位置不能描述拇指关节弯曲。 | 使用第 2、3、4 号关键点计算大拇指关节夹角。 |
| 程序启动时存在突然运动风险 | 若启动即发送固定姿态，物理方向未校准时可能误动作。 | 启动后只等待识别到手部动作，不自动发送张开姿态。 |

## 5. 最终成果

### 5.1 已完成能力

- 摄像头实时识别操作者左手，并在窗口中显示关键点。
- 通过 `COM3`、`115200`、ID `1` 控制 RH56DFTP-2L 左手灵巧手。
- 小拇指、无名指、中指、食指可分别跟随弯曲和伸直动作。
- 大拇指控制算法已改为关节弯曲角度，目标是在张开和握拳时实现向掌心收拢。
- 大拇指旋转轴被固定，避免错误的横向外摆。
- 提供串口独占提示、命令限幅、死区、频率限制和丢失手部时暂停发送等基础安全措施。
- 提供可双击的 Windows 启动脚本。

### 5.2 验证结果

自动化测试命令：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

最终测试结果：`18 passed`。

实机调试中已验证摄像头关键点识别、串口连接、四指基本跟随和手势映射调整流程。自动化测试验证的是软件映射和协议逻辑；由于机械手会直接运动，今后更改轴方向、角度范围或增益后，仍应先在手周围无障碍物的条件下逐根手指做小幅验证。

## 6. 使用说明

1. 给灵巧手接通 24V 电源，并连接 USB-RS485。
2. 确保因时上位机已经关闭。
3. 双击 `启动灵巧手跟随.bat`。
4. 将物理左手放入摄像头画面；窗口出现黄色点位后开始跟随。
5. 按 `Esc` 停止程序并释放串口。

预览摄像头而不控制硬件时，可运行：

```powershell
.\.venv\Scripts\python.exe -m hand_tracking.app --config config.yaml --no-serial
```
